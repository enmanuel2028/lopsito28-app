Política de privacidad

Última actualización: 24 de agosto de 2026

Esta política explica cómo la herramienta Casos Oscuros maneja la información. Es una herramienta de uso personal, creada y usada por el titular del canal de TikTok @lopsito28 para producir y subir sus propios videos.

1. Qué información se maneja

  • Token de acceso de TikTok: al autorizar la aplicación, TikTok emite un token que permite subir videos a la cuenta del propio titular. Ese token se guarda únicamente en el computador personal donde corre la herramienta.
  • Nombre de usuario y datos básicos del perfil: se consultan solo para confirmar en qué cuenta se está subiendo y qué permisos hay disponibles.
  • Estadísticas de la propia cuenta (seguidores, likes totales, cantidad de videos) y la lista de los propios videos publicados con sus vistas, likes, comentarios y compartidos: se leen únicamente para que el titular haga seguimiento del crecimiento de su canal. No incluyen datos de ningún otro usuario de TikTok.
  • Los videos producidos: archivos generados localmente y subidos a la cuenta de TikTok del titular.

2. Qué NO se hace

  • No se recopila información de otros usuarios de TikTok.
  • No se venden, comparten ni transfieren datos a terceros.
  • No hay servidores propios: la herramienta corre localmente y no envía información a ningún servicio distinto de las APIs necesarias para su funcionamiento.
  • No hay registro de usuarios ni cuentas de terceros: la herramienta no es pública.

3. Dónde se guarda

El token de acceso se almacena en un archivo local del computador del titular, con permisos restringidos, y nunca se sube a repositorios ni se comparte. Los videos y sus archivos asociados quedan en el disco local.

4. Servicios de terceros

Para funcionar, la herramienta se comunica con:

  • TikTok API — para autorizar la cuenta y subir los videos.
  • Google Gemini API — para redactar el guion de cada caso.
  • Cloudflare Workers AI — para generar las imágenes de las escenas.

Cada uno de esos servicios tiene su propia política de privacidad, que aplica a la información que se les envía.

5. Retención y borrado

El token se conserva mientras la herramienta esté en uso y puede borrarse en cualquier momento eliminando el archivo local o revocando el acceso desde la configuración de TikTok. Al revocarlo, la herramienta deja de tener cualquier acceso a la cuenta.

6. Cambios

Si esta política cambia, la fecha de arriba se actualizará.

7. Contacto

Consultas por mensaje directo a @lopsito28 en TikTok.
